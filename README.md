# RoboShop Catalogue – Jenkins CI/CD

This project demonstrates a CI/CD pipeline for the RoboShop Catalogue service using Jenkins and GitHub.

## Pipeline Stages

- Checkout – Pulls the latest code from GitHub
- Build – Builds the Catalogue application
- Test – Validates the application
- Deploy – Deploys the application to the target environment

## Technologies Used

- Jenkins
- Git & GitHub
- Linux
- AWS
- Docker
- Shell Scripting

## Jenkins Pipeline

The project uses a `Jenkinsfile` to automate the CI/CD process.

Jenkins Job:

`roboshop/catalogue`

The pipeline has been successfully executed through multiple builds.

## Objective

The objective of this project is to demonstrate the implementation of a Jenkins CI/CD pipeline integrated with GitHub for automating the build, test, and deployment process of a microservice.

## Result

The Jenkins pipeline successfully executes the configured stages and provides build history and status through Jenkins.
